Create batches

Upload a sheet of batches. Each row is created on Skill India (NSDC) and comes back with a batch ID.

  • Accepts .csv and .xlsx, up to 10 MB.
  • All 21 batch columns are required — use the template below to get the exact names. There is no size column: the size is counted from the students already uploaded for that batch.
  • Upload the students first. A batch nobody has been uploaded for is not created, since its size would be zero.
  • A batch whose name already exists is not created again. NSDC does not refuse a repeated name — it quietly makes "Academy Sep26(2)" — so the portal stops it here.
  • Dates are read the same way the existing batch script reads them, so 10-Jan-2026 and 1/10/2026 2:00:00 both work.
  • sector, schemeType and createdSource are fixed values the script always sends; they are not columns in the sheet.
  • Preview payload only validates the sheet and shows the exact JSON that would be sent to NSDC — no request is made and no batch is created.
  • NSDC renames a clashing batch, so "Academy Dec25" can come back as "Academy Dec25(2)". The result sheet shows the name NSDC actually used.
Dates must be readable — YYYY-MM-DD is safest 2026-09-01, 01-Sep-2026 and 9/1/2026 2:00:00 all work here, as they do in the existing batch script.
