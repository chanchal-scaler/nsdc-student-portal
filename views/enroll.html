Enrol students in batches

Students whose sheet named a batch are enrolled here. Candidate and batch IDs come from what the Students and Batches pages stored, so there is nothing to fill in — a student waits until the batch they name exists, and one already enrolled is not enrolled again.

From the student sheets

Download the list instead

Or upload a sheet, one row per enrolment. The list above can only offer each student the one batch their student sheet named; a sheet here can name the same student as many times as they have batches — an SST student sits in a different batch each year of their tenure.

  • Accepts .csv and .xlsx, up to 10 MB. Columns: candidateId, batchId, email, batchName.
  • Name the student either way, and the batch either way. A row needs one of candidateId/email and one of batchId/batchName. Emails and names are looked up from what the Students and Batches pages stored; IDs are used as they are.
  • IDs reach batches this portal never created. A batch made on NSDC by hand has no ID stored here, so its name resolves to nothing — give the batch ID and it enrols anyway.
  • Batch names read as <Programme> <Month><YY> — Academy Sep26, DSML July27. Programme is one of Academy, DSML, DevOps, AIML, OPGP, SSB. SST runs in years, so its batches read as <Programme> <YYYY> <Course> Year <n> — SST 2023 CS-AI Year 3, course one of CS-AI, AI-B. A month with more than one batch numbers them in brackets, after a space — Academy Sep26 (1). A batch named any other way is still reachable by its batchId.
  • The same student on four rows with four batches is the point of this sheet, and enrols into all four. The same student and batch twice is a slip, and is sent once.
  • Students already recorded as enrolled in that batch are skipped, so the same sheet can be run again safely.
  • Preview payload only resolves every row, shows whose ID each one turned out to be and the exact JSON that would be sent — no request is made and nobody is enrolled. A mistyped candidate ID is still a real candidate ID, and NSDC enrols whoever it belongs to without complaint, so this is the one place to catch it.
