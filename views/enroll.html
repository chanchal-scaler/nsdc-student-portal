Enrol Students in Batches

Download student dataUpload studentsCreate batchesComplete batches

Upload a sheet of students and the batch each one belongs to. Candidate and batch IDs are looked up from earlier uploads — the sheet only needs an email and a batch name.

  • Accepts .csv and .xlsx, up to 10 MB. Two columns: email and batchName.
  • Every student going into the same batch is enrolled in one request, the way the existing script does it.
  • A student whose email has no stored candidate ID is reported, not sent — upload them on the Students page first.
  • A batch name with no stored batch ID is reported too — create it on the Batches page first.
  • Students already recorded as enrolled in that batch are skipped, so the same sheet can be run again safely.
  • Preview payload only resolves the IDs and shows the exact JSON that would be sent — no request is made and nobody is enrolled.
